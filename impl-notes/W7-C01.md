## Decisions and canon corrections

- ARCH-0026 (`generated/oneiron/agents/oneiron-arch-0026-dreamer-v2.md`):
  relationship-absent means the all-relationships scope, not permission to merge
  a relationship-scoped belief into every other scope. Equal absent axes merge.
- ARCH-0027 (`generated/oneiron/agents/oneiron-arch-0027-import-pipeline-v1.md`):
  the shipped `IngestSource` trait has normalization hooks, not the accessors
  described by the prose. `parse_import` now supplies the shared pre-semantic
  shape without replacing the trait. Missing source timestamps remain `None`;
  they must not be fabricated. `recordedAt` is supplied by the import host.
  Platform identifiers are registry data over generic layouts, not branded
  engine modules. The source interface consumes a host-provided directory
  snapshot and never walks arbitrary paths. OKF URIs are resolution requests,
  never trusted assignments. Vendor histories remain evidence Records.
- OF-180's identity §§6.1–6.5 pointer predates the current identity hub.
  Current identity canon kills a separate device-key widen ceremony (OF-452).
  Implementation must reuse authenticated owner authority, never introduce a
  competing credential or interpret frictionless confirmation as widening.

### Consolidation policy decisions

The v1 selection defaults are JSON data, loaded through a per-vault row override.
Soak defaults to zero to keep immediate consolidation available; the evidence
minimum defaults to one. Strength is the primary order, and the independent
`fan_in*(1+new_refs)` signal breaks strength ties. Weights are 0.7 Type-Prior
and 0.1 each for frequency, recency, diversity. The validator requires Type-Prior
weight to exceed the sum of the other weights. These are authored v1 rows, not
numbers handed to the judge.

ARCH-0003 §G.1 leaves per-predicate topic derivation unpinned. The current
implementation uses a structured value's `topic` field for the four named
set-cardinality rows, with whole-predicate question fallback when no explicit
topic exists. It never keys a question on its answer. All qualifiers remain in
the value key. Rules are operator-editable vault data. Prior-head evidence
attachment remains to be integrated; current mechanical attachment joins
siblings before the existing promotion path.
