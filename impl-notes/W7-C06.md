## Canon/code corrections

- Historical high-water marks cannot be compared against every prior entry during each
  fold. Immutable admission observations preserve historical validity while refusing new rollback.
- Selector-fetch requests are not CRDT row-rematerialization markers. Deferral stores real
  request bytes and has a retry/completion protocol; automatic replay is not a renamed Pause.
- Missing manifest stamps are never trusted. The built-in seed and local raw test fixtures
  explicitly record local authorship. Exact replay echoes retain authority only while the
  same locally authored row still occupies its slot.
- A human's actor ceiling is not a human-confirmed foreign grant. Introduction authority
  is explicit and separate. A legacy product CONNECTION kind is not a current engine type.
- The merge judge already existed; the production gap was empty prior-head input and
  missing durable conflict markers. No second judge was invented.
- Default shared membership is stored data, not runtime preset policy. Personal/community
  default ordinary additions to Viewer; family/team/org to Member. Owner is explicit.
- Equal-holder newest-wins uses logical ledger order, not a caller's wall-clock timestamp.
- The base export format had no whole-vault restorable serializer. Entity enumeration and
  nulling are implemented; the result does not claim to preserve edge/index restoration.
- Anonymous means no bound engine persistence. It cannot promise deletion of provider logs.
- The separate ONE-1548 dependency was not a usable moderation primitive in this checkout.
  Human-row parsing, hash-only queue and Hold enforcement were added on the existing policy plane.
- Live tag-name research is nonblocking in its own contract, but remains an explicitly unrun
  acceptance item here. No invented model scores or significance conclusion is included.

- Witness MESSAGE relationship scope comes from typed fields in its authenticated metadata,
  not from prose or a fabricated raw message write. Ambiguous duplicate axes fail closed.
- Credential filtering runs on native MessagePack before lossy JSON conversion. Raw serving
  retains safe binary/ext types; export nulls secrets and records that fact in its manifest.
- Booking confirmation uses commit time; the publication's historic validity interval is a
  separate read-time condition. Attributed revisions still wait for owner confirmation.
- Structural failure streaks follow durable receipt append order, including same-clock-tick
  receipts. A random UUID ordering must not move a later success before an earlier refusal.
