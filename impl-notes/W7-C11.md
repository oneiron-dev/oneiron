### Canon decisions for the newly integrated modules

DAG canon: `oneiron/backend/oneiron-arch-0006a-conversations-api-core.md` and the CONV-01/02 SOW. HEAD/canonical/session sidecars stay local. Reply revision hashes the encoded TURN body; late headers append through the engine door. Legacy writes cannot add invisible bare records to an adopted DAG.

The recovery driver returns fresh state and restores standard materialization; the caller owns stopped-writer coordination and live-window publication. No historical redaction-sweep completion is asserted.

Ports canon: `oneiron/backend/oneiron-arch-0005a-backend-ports-integrity.md`. Transactions stay caller-owned. Adapter methods must not start or commit nested writers. Explicit conformance adapters are not proof of complete production migration; remaining direct callers are being moved separately. Existing overlay/session reads must retain their view semantics.

Streaming canon: `oneiron/core/oneiron-arch-0002-structural-entities.md`, Streaming MESSAGE write path. Receipts are written inside the existing witness transaction, after MESSAGE validation and before final actor revalidation. A refused finalize retains its buffer and commits neither MESSAGE nor receipt. Buffers never become partial CRDT ops.

### Android API26 static repair

The final compatibility audit found a concrete new Android build defect. In pinned libc 0.2.189, Android's `RENAME_NOREPLACE` is `c_int` but `renameat2` expects `c_uint`. More importantly, Bionic's `stdio.h` marks `renameat2` `__INTRODUCED_IN(30)`; the adapter's NDK linker targets API26. The Linux/Android recovery branch now calls `libc::syscall(SYS_renameat2, ...)` instead, keeping atomic no-clobber semantics without requiring the API30 Bionic symbol. Unsupported kernels return an error; no overwrite/copy-unlink fallback is added. Existing `quarantine_uses_next_invalid_suffix_for_distinct_existing_bytes` and `quarantine_skips_symlink_candidate_to_preserve_bytes` are the behavior falsifiers. The changed syscall branch has not been compiled or rerun because of the build-host block below.

Source evidence: matching cached libc `src/unix/linux_like/android/mod.rs` (constant and declaration) and Android's authoritative `https://android.googlesource.com/platform/bionic/+/refs/heads/main/libc/include/stdio.h?format=TEXT`.
