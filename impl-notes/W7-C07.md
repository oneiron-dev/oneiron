## Integration details
- Local writes stamp a deterministic PERSON substrate or an explicit mask. CLAIM v2 requires all four scope keys. The one-time sweep handles pre-axis rows; raw and replay writes never silently upgrade incomplete new stamps.
- Stored grants carry six-axis Scope; selectors and budget counters only narrow it. Schema 1.1 migrates to 1.2 once. Current empty/partial Scope remains Bottom. Retired SetCeiling history decodes inertly; new append is refused.
- Common Scope and causal checks cover retrieval, hydration, sync, export and deletion. Unknown stamps stay hidden unless the explicit debug view is used. Deleted metadata requires full-position authority, any named-ID bound, and a live slip. No deleted body is disclosed.
- CLAIM envelopes carry the observed authority frontier. Replay never invents one. Concurrent revokes dominate grants; only causal descendants of regrant authorize writes. Existing rows can become quarantined without losing raw evidence.
- Logged slips use v2 MAC chains, caveat meet, expiry and holder binding. Revoking a parent kills its subtree. Empty named-record/channel intersections remain denied. Atomic one-shot redemption consumes applicable ancestors. Admission consumes a holder-proof nonce once, including HTTP, WebSocket and app-tier binding.
- Pairing preserves owner-approved principals and closed org powers. MCP registration is metadata plus a ceiling, not authority; unrelated host credentials cannot lend it root access. Managed custody derives its issuer from the verified vault DEK, not a per-spawn callback token.
- Fanout admission precedes TASK mint. Exact-digest authenticated rulings, Gate receipts, ED-06 remembered caps and resumed TASKs share the transactional door. Board rows expose total/per-peer counts and pause evidence.
- T2 fixture roots use canonical temporary paths on macOS. Production symlink rejection and all negative path checks remain unchanged. Selector fixtures now use binary CLAIM scope IDs. The edge-shipping fixture uses a real PERSON provenance actor outside its mirrored window and positively stamps all read controls.
- The pending-claim index fixture hashes the actual committed body, including its writer stamp, rather than the pre-write candidate. All replay/index preservation assertions remain.
- The root surface intentionally drops only `CompanionExportClassification`; new persona types are exported under `companion`, not the root. No lint allowance, process-global state or ratchet budget was added.
