## Decisions and canon gaps

- OF-335 has only a registry intent, no weighting or unknown-subject rule. The implementation uses equal-weight normalized signals and a neutral, explicitly absent default. There are no diagnosis/severity fields. Producers remain responsible for their measured signal claims.
- ARCH-0067: a Child consult addresses the already running child's actor identity. Its TASK is inbox input; it never silently spawns another worker. Dreamer has no distinct actor row and uses the existing owner execution binding.
- OF-352: automatic agreement can settle a review, but cannot train Beta posteriors. Anchored outcomes require an owner-bound human act. Findings remain private artifacts; verdicts and outcomes are claims with session provenance. The node-local projector binds emitted claims to private content digests; raw/synced claims are not calibration events. Retries return the immutable stored result, not a fresh computation after posterior drift. This is a local trust decision, not a new replicated authority grant.
- ARCH-0053 manifest revision choice: tier-1 index uses the dependency-list content hash; actor claims use the encoded body hash. Neither uses an invented revision counter. Skill pulls retain the stored semantic version. The engine exposes attempt-bound load doors because ordinary repository reads have no attempt identity.
- ARCH-0027 export currently carries structured entity values, not raw database bytes. Credentials and opaque unknown binary are nulled. Foreign import never replays authority or approved state. Unsupported reserved/witness families refuse atomically pending their typed adapters; this is not a full owner-restore format.
- WORKFLOW byte 18 is free in this engine registry; `wf` is its short prefix. The future registry re-key and a schema page should include it. A workflow is inert ordered AGENT_DEF references, not a second code-mode runtime.
- The ARCH-0027 sentence saying TOON still calls `toon_format::encode_default` is stale. This base already has the native tabular encoder.
