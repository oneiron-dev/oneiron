## Result and boundaries

This change implements the engine-local surface work below. It is **not full
cluster acceptance**. Production JavaScript execution, authenticated cross-peer
NOTE transport, the Python BaseStore satellite, and downstream V2 deployment
remain incomplete. The docs mirror was read only. No product integration,
migration, billing logic, unchecked document importer, or fake KV store was
added to the engine.

## Decisions and canon corrections

- NOTE/brief/editor: `oneiron/core/oneiron-arch-0032-agentic-notes-v1.md`.
  The contract omits concrete brief defaults; the conservative pack choices
  above are policy seeds, not grants. Stored HTML is not a NOTE body.
- Sandbox/tool projection:
  `oneiron/agents/oneiron-arch-0028-mcp-external-agent-surface-v1.md`.
  Checked-in `oneiron:code-run/guest@1.0.0` is the source for imports and JS
  declarations. Wasmtime is optional behind `code-sandbox-wasmtime`; generated
  whole-world linkers are not used to accidentally grant foreign writes.
- Lens/ROOM/observe: `oneiron/surfaces.md` and
  `oneiron/surfaces/oneiron-arch-0048-genui-protocol.md`. The repository's
  CodebaseScopeKey WorldSet is narrower than the general world-set prose.
- L2: `oneiron/agents/oneiron-arch-0026-dreamer-v2.md`. The digest covers
  canonical evidence bytes, not just rendered text. Confidence/evidence
  changes can change the hash, but neither ranking scores nor confidence
  values enter the rendered base. Cache locks cover only lookup/publication;
  fresh hydration revalidates authority and evidence under its read snapshot.
  Erasure fences prevent an older reader from repopulating erased evidence.
  Unstamped Tier-A evidence is correctly withheld despite an allowlist; the
  positive HTTP fixture labels evidence public and also tests a private rewrite.
- Wire: `oneiron/surfaces/oneiron-arch-0044-public-surface-ws.md`. “Full facade”
  means the actual four-row FACADE_VERB_CATALOG, not every internal engine method.
  npm reported 22,696,952 `ai` downloads for 2026-09-10–2026-09-16; PyPIStats
  reported 47,362,821 `langgraph` downloads in its last-month window at pickup.
- Board: `oneiron/agents/oneiron-arch-0067-context-board-v1.md`. Tracking is
  session-owned, never process-global. Capability discoveries use the turn
  clock; loaded bodies use the session clock. Riders are not new push traffic.
- Reactivity: RD-23 v86 and CROSS-ARCH-0020. Read sets and membership probes
  are distinct; the old dropped-diff queue metadata had to be repaired for
  entity-granular invalidation to reach actual subscriptions.
- Downstream: `cross/infrastructure/cross-arch-0021-eiri-live-wire.md`. The
  held migration prose must not be interpreted as authority for a cutover.

## NOTE transport prerequisite

This branch's sync schema carries entities, edges and tombstones, not Loro
entity-document operations. ONE-2540, ONE-2541 and ONE-2542 own the missing
registry and transport. A Loro commit's actor text is not peer authentication.
No unchecked snapshot importer was added merely to pass a two-peer fixture.
Integration must co-commit document ops, reverse pins and outbound intent;
apply selectors to cited sources; preserve admitted provenance; and reject
forged stamps, unauthorized edits, citation bypass and erasure replay before
publication. Raw immutable NOTE birth bytes remain the identity; live body
reads project the admitted document under their current transaction.
