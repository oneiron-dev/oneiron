New APIs live under existing public modules, not the flat crate root. The root remains at 701 names. No image SDK, process-global state, or lint allowance was added.

Raw adapters do not retry, allocate budgets, or write deltas. The step layer owns retries, named deterministic fallbacks, schema correction and terminal memoization. Fallback finish reasons record runner/failure provenance; corrective spend survives fatal fallback and memo replay. JSON schema remote fetching is disabled. Agent-loop calls do not pass through this one-shot shim.

Manifest route overrides can only narrow locality. VERDICT consults retain the existing owner/confirmation exclusions and can only hold a rule-granted write. Preflight and apply share one LMDB write transaction, so a preflight receipt cannot cross a manifest revision. The enforced-hold fixture retains an existing Proposed claim; shadow mode permits the ordinary write and records the hold reason.

The host injects the tagger/checkpoint and calibrated checker. Shadow tagging has no write door. Surprise receipts name the input refs and are included with the delta in the canonical request, preventing memo reuse across different inputs. Named Dreamer runners pass argv and credential handles through the existing CLI sandbox. User-login dispatch is refused on Hosted nodes both at admission and execution replay.

The vendor seed is a public OpenRouter snapshot fetched from `https://openrouter.ai/api/v1/models` on 2026-09-19. Its 54 real provider rows carry source prices converted to per-million without floating-point rounding. `~` routing pseudo-providers are excluded. The engine identity normalizes `:free` to `.free`, while `wire_model` preserves the exact upstream name. Revisions are explicitly catalog-snapshot revisions, not invented immutable provider revisions. Hosts can replace discovery bindings with production pins. Registry reseeding never overwrites prices or scores. Unchanged score observations advance the freshness watermark but do not add diff rows; score updates never route an answerer.

Owner voice register clips remain private per-vault data. Clone reads return owned copies for each render target. Vendor-origin identity writes are rejected. Provider read formats sanitize before truncation as well as during serialization.
