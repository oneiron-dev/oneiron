## Decisions and canon corrections

- OF-464: the typed scope API stays `Option<EntityId>`. The wire always writes
  `world: base` / `rel: all` for `None`, or a binary entity ID. Absent tags fail
  decode, including replay. No legacy decoder: REVIEW.md says pre-release.
  The context pack's compatibility warning was stale. Relationship IDs now
  pass the same off-record reference fence as world IDs.
- Rule A: one receipt rides each durable Loro Change message. Its document and
  exact operation span come from the log, so no self-referential frontier is
  stored inside the document. The row fold excludes any unreceipted commit.
  The existing peer-to-actor authority remains separate from derivation data.
- Cold attach: a marker lands atomically with the first model identity. The
  serve worker consumes it with the backfill scan in one transaction. Retries
  do not double-fill, hotter jobs retain urgency, and no migration epoch moves.
- OF-360 corpus: 500 explicitly synthetic, owner-authorized memory points in
  50 varied scenarios. This is not real owner data. Grounded QA is separate
  from extraction matching. Missing answers stay in the denominator.
- Edit path: the oracle copies only fixture source units into a clean crate.
  Candidate manifests, build scripts and tests cannot replace its checks.
  Success requires functional AND contract tests. Regressions stay separate.

  resources. A resource missing its master refuses before admission; it is
  not treated as evidence that the master disappeared.
