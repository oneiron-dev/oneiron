# Contributing to Oneiron

Oneiron is open source so that you can use it free, fork it, and build your own version. Thank you for taking a look.

## Start with an issue

An issue is the best way to help. Open one for a bug, a question, or an idea.

For a bug, tell us:

- the Oneiron version or commit;
- your OS and how you run Oneiron;
- the steps that show the bug;
- what you expected, and what happened;
- any log output or error text.

For an idea, describe the problem you want to solve. The problem helps us more than a finished design.

## Pull requests

We read every pull request as a proposal. For each one, we do one of these:

- merge it as it is;
- rework it and land it from our own branch, with credit to you in the commit;
- take the idea and build it our own way;
- close it, when it does not fit where Oneiron is going.

A small pull request with one clear change has the best chance. Say what changed and why. For a larger change, open an issue first, so that you do not spend time on work we cannot take.

## CI on pull requests from forks

Our CI runs on our own machines, so we do not run it for pull requests from forks. When we take a change, we land it from our own branch, and CI runs there. A fork pull request with no checks is normal.
