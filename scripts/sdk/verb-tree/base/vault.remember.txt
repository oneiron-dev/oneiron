vault.remember({ subject_ref: string, predicate: string, value: unknown, confidence: number, source: string })
  -> { claim_short_id, approval: "auto" | "proposed", superseded_short_id, receipt_ref }
  Adds one claim: one fact about one subject. A claim with the same subject_ref and predicate replaces the
  standing one (superseded_short_id names it), except on set predicates (decision.*, relationship.*), where
  claims stand side by side. Facts that must stand together take a predicate each (experiment.run_result.d1a)
  or a subject each.
  subject_ref: the short_id of the record the fact is about. A project's facts and decisions go on the project
    (vault.recall finds it, kind PROJECT). Facts about yourself go on (await self.actor({})).person_ref.
  predicate: a dotted lowercase name you choose, each part [a-z][a-z0-9_]*; one subject holds one standing
    claim per predicate, except set predicates.
  value: text or JSON. confidence: 0 to 1 (0.9 and up for what you read in a source). source: the file, log or
    person the fact came from.
  approval "proposed": held for the owner, and it replaces nothing yet; it is in vault.writes.pending and not
    yet in recall.
  e.g. await vault.remember({ subject_ref: me.person_ref, predicate: "experiment.run_result.d1a",
         value: { run: "1127-0912-d1a", verdict: "pass" }, confidence: 0.9, source: "run log, 26 Nov 2026" })
