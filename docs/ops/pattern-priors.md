# Pattern hints on learning payoff cells

A bound pattern's `works_well_for_types` supplies its weak model prior for an
exact matching task node when the cell has no stored prior and learned backoff
finds no evidence. The default uses the same existing mean, 0.65, and weight,
2 runs, as `register_pattern_skill`.

The read applies to the native pattern payoff cell shape: Beta reliability,
`payoff` axis, an executor and a type, with no consent-scope or setting-key
qualifier. It does not infer ancestors, parse the prose into new type names,
claim a measured result for any executor, or invent a model inventory. The
current binding names the node; its weak default can serve each actual asking
executor and project at the current tree version.

Precedence remains:

1. The cell's own head.
2. Its owner's setting seed or stored prior, as the shared learning reader
   already handles those origins.
3. The existing measured and stored vault-twin, parent and carried backoff.
4. The matching pattern hint, then the old shipped default.

A computed hint is not mistaken for a stored vault-twin prior. Reads add no
`PRIOR` row. Projection uses the same resolved hint when it folds real evidence,
so the 2-run prior and the evidence share the existing posterior/frozen-input
path. Team-receipt capture still does not store a hint-only read.

The existing skill-reliability first-own-run writer is unchanged. If a real
attempt-pack receipt names this supported pattern payoff cell, that writer
may capture the resolved hint like its other starting priors. Once captured,
it has the normal first-wins stored-prior precedence. This is not a new writer
or a new permission check.

Explicit `put_cell_prior` and `register_pattern_skill` replacement behavior is
unchanged. Existing priors and evidence are not overwritten by a read.
The fallback requires the canonical pattern source to be a live SKILL; a
retained binding cannot resurrect a deleted or missing skill's prose. Existing
stored priors and historical heads are not changed by this check. A missing
binding, an empty type list or a nonmatching node keeps the old learning default. This does not install or bind hub patterns; that requires
actual pattern metadata and the native import path, not embedded skill copies.
