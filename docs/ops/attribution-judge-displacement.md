# Displaced judgments and anchored credit

An explicit judge displacement keeps the original judgment and sealed credit
receipt as history. Its displaced numerical evidence must leave active learning
projections. Recording a judge score conversion is a different operation and
does not count as displacement.

For a failed anchored credit, a direct subject's loss stands unless its actual
seating judgments form a non-empty set and every one is marked displaced. The
join uses the credit's exact attempt reference, attribution evidence sequences,
and persisted SkillDefect or ExecutionLapse judgments for that subject. All reads
use the caller's transaction. A live seating judgment, a missing judgment, an
unknown seating subject, or no seating proof keeps the existing loss.

When that failed direct loss becomes absent, the anchored join uses its existing
withdrawal path under the stable credit-receipt key. Only a context-bearing row
can take this withdrawal. Context-free recovery rows keep their separate
no-new-withdraw behavior. The sealed credit receipt is not edited or deleted.
The shared standing-credit read also stops that displaced loss from contributing
to the existing person-row recomputation.

A successful credit and an independent standing amendment's first-priority loss
keep their existing behavior. This does not infer a judge from an old score
field or change the evidence admission rules.

The amendment-reliability producer checks the actual source judgment's judge
revision against the explicit displacement fence. It omits a displaced verdict
before choosing the newest floor context and before choosing the later verdict
for an attempt. An earlier live verdict can therefore remain standing. Unknown
or undisplaced judges are not omitted. The existing amendment row shape and
withdrawal-by-absence reconciliation are unchanged.

After the displacement marker writer commits, supersede runs the existing full
amendment reconcile once, before its ordinary affected-skill reproject loop.
This reaches amendment-only subjects without requiring a later unrelated pass.
There is no nested writer. An error propagates, the truthful markers remain, and
a repeated supersede retries the same idempotent reconciliation.

ExecutionLapse actor credit is reconciled inside the marker writer, after all
matching judgments have their markers. Only an existing failed direct-credit
row with the exact stored credit, attempt, context and cell coordinates can
leave. Missing provenance or any live seating judgment keeps it unchanged. The
same attempt's existing driver row is recomputed across the credit's effective
subjects; a standing loss from another subject survives. Its key, coordinates,
anchor, time and other provenance stay unchanged. No actor is passed through
skill priors, confidence caches or floor proposals, and no missing driver row is
created. Repeated supersede uses the same idempotent path.
