# Signed Connect origin positions

Connect exports can now carry the stored birth positions of a source-bound
ASSET_TEXT and every source ASSET that the same guest export actually carries.
The `origin_positions` Loro root is inside the existing signed ConnectWindow
update. It is not a new signature, permission, wire tag or side table.

The source compares each exported carrier with its current canonical row on
one read snapshot. It binds the full metadata header and body or file manifest,
the masking-safe birth process/time/input hash, the stored scope, the one birth
facet and the caption's exact DerivedFrom set. Every source must be a live
ASSET under that same facet. These witnesses describe native base-born positions;
they do not infer positions from peer-provided edges or turn an unstamped row
into a local birth.

Only the already verified, immediately Imported Connect branch can invoke the
receiver importer. It checks the current pact, pinned source key, epoch and
unchanged live local grant again in its writer. It compares the signed carriers,
birth incarnations, facets and source set with the actual current rows. A file
ASSET also needs its exact bound reference, complete current descriptor and a
successful streaming check of the resident file. The authenticated source's
base world maps through the normal foreign-world mapping. Other signed axes
stay unchanged; audience and sensitivity are not recipient permissions.

Positions are installed beside matching rows in that same writer. A conflicting
existing position is never overwritten. Source positions are checked first;
a caption gets its position only beside all matching source positions. Later
content writes inherit that verified foreign position rather than attempting
to replace it with a new base-world birth. Every normal read still checks the
current reader's six axes, every live readable source and causal admission.

Missing or invalid witness evidence does not reject the previously supported
raw Connect export/import. A failed optional witness pass records a value-free
warning and leaves the original raw operation unchanged. Generic federation
admission does not retain or forward the new root as authority.

## Boundaries

This closes the immediate Imported case with current matching caption/source
rows and resident file bodies. Deferred/Pending replay, later body arrival,
unsigned live delivery and multi-hop origin positions remain separate work.
Intrinsic record-world placement is unchanged; it still differs from a
translated scope for these kinds (FIX13312). No runtime or complete FIX40
closure is claimed by this source change.

There is no deployment setting, new numeric limit, format compatibility reader,
migration or retention rule. No tests were added or run under the owner decree.
