# Code map

Orientation map of Rust crates under `crates/`: one row per crate, then one table per crate at the top-level-module grain.
Scope excludes `heed`, `vendor/`, and `target/`. Other workspace members, including [oneiron-macos](../apps/macos/src-tauri/), are not indexed here.
Read this overview first, then search `codemap/<crate>.md` by module path or type for the per-file table (kind, size bucket, pub surface, notable types). Do not load large crate maps, especially `codemap/oneiron.md`, in full.
Generated by `python3 scripts/codemap/codemap.py` — never edit by hand.
Regenerated on main by `.github/workflows/codemap.yml`; PRs never touch it; run the generator locally only to read a fresh map.
`--sizes` prints the live line-count table (never committed).
Test files follow the ratchet definition: a `tests/` path component, `tests.rs`, or `*_tests.rs`.
Size buckets are line counts of the whole file: `s` < 300 · `m` 300–799 · `L` 800–1499 · `XL` ≥ 1500.
`L` or `XL` on a non-test file means the file is over the 800-line ratchet bar (`scripts/ratchet/check.sh`); split it, do not grow it.
